Schema markup validator

Schema markup validator with a 3D entity graph.

A schema markup validator checks structured data, usually JSON-LD, for syntax errors and missing or malformed properties so search engines can parse it. This validator checks JSON syntax, the schema.org context, required and recommended properties for common types, absolute URLs, ISO 8601 dates and how entities connect by @id.

What this validator checks

  • Syntax. Invalid JSON is the most common failure: trailing commas, smart quotes from word processors, unclosed brackets. We point to the line.
  • Context. Every block needs "@context": "https://schema.org".
  • Required properties for 25 common types, including LocalBusiness, Organization, Product, Offer, Service, FAQPage, Article, Event, HowTo, BreadcrumbList and VideoObject.
  • URLs and dates. Properties like url, image and logo must be absolute. Dates must be ISO 8601.
  • Connections. We follow @id references so you can see whether your business, pages and services form one connected graph or float as strangers.

What it cannot tell you

Valid is not the same as right. A validator cannot know whether your schema matches what is visible on the page, which types your pages should use, or whether your markup qualifies for a rich result. Google's Rich Results Test answers eligibility. Strategy answers the rest.

Common schema mistakes we fix

We wrote them up in schema markup mistakes we fix most often. The short version: review markup about yourself, schema that describes content the page does not show, disconnected entities, and relative URLs.

FAQ

Questions, answered straight

What is a schema markup validator?

It is a tool that checks structured data, usually JSON-LD, for syntax errors and missing or malformed properties, so search engines can parse the markup and understand the entities on a page.

Is this the same as Google's Rich Results Test?

No. Google's Rich Results Test checks whether markup is eligible for Google rich results. This validator checks structure against schema.org conventions for many types and visualizes how your entities connect. Use both.

Does my code get uploaded anywhere?

No. The validator runs entirely in your browser. Nothing you paste is sent to a server.

Why does it warn about review markup?

Google does not show review stars for self-serving reviews, meaning reviews a business marks up about itself on its own site. The markup is not always wrong, but it will not earn stars and can look manipulative.

What schema type should my business use?

Most local businesses should use the most specific LocalBusiness subtype available, such as Plumber or Dentist, connected by @id to WebSite, WebPage and Service nodes. The right structure depends on the site.
