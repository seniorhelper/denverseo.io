llms.txt generator

llms.txt generator: give AI tools a map.

An llms.txt file is a short Markdown file at your site root that tells language-model tools what your site is and where the important pages live. Build yours in a minute.

llms-txt-generator
llms.txt is a proposed standard, published at llmstxt.org, for a Markdown file placed at a website's root (/llms.txt) that summarizes the site for large language models and links to its most useful pages. It starts with an H1 name, then a blockquote summary, optional details, and H2 sections of links.


Does llms.txt actually do anything?
Honest answer: it is a proposal, not a requirement, and support varies. Some AI tools and developer platforms read it. Major search engines have not said they use it for ranking. It costs almost nothing to publish, and it forces a useful exercise: deciding which pages actually represent your business.


What matters more is what the file points to. A tidy llms.txt linking to pages full of vague marketing copy helps no one. Link to pages that answer questions clearly, with structured data that matches. Our own llms.txt is live if you want an example.


Format rules this tool follows
  • One H1 with the site or project name.
  • A blockquote with a short summary.
  • Optional paragraphs of detail.
  • H2 sections containing Markdown link lists, each link with an optional note after a colon.
  • An optional section named "Optional" for secondary links that can be skipped.

FAQ
Questions, answered straight
What is llms.txt?
llms.txt is a proposed standard for a Markdown file at a website's root that gives large language models a concise summary of the site and links to its most important pages.
Where do I put my llms.txt file?
At the root of your domain, so it loads at yourdomain.com/llms.txt, served as plain text.
Does Google use llms.txt?
Google has not said it uses llms.txt for search. It is read by some AI tools and platforms. Treat it as a low-cost signal, not a ranking factor.
What is llms-full.txt?
A companion file some sites publish containing fuller content, such as complete documentation, in one Markdown file for tools that want everything in one fetch.
Should I block AI crawlers instead?
That depends on your goals. If you want to be cited by AI search, crawlers need access. Check what your robots.txt allows with our AI crawler checker before deciding.
